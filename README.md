# BOJJIMI × RUBIE Cosmetics Store

보찌미를 루비에 중심의 화장품 전문 판매몰로 전환한 Flask 애플리케이션입니다.

## 주요 기능

- 화장품 전용 홈·브랜드·카테고리·상품 상세
- 판매 전 제품을 위한 `출시 준비` 상태
- 회원가입·로그인·마이페이지
- 비회원 및 회원 장바구니·주문·결제
- 토스페이먼츠 V2 주문서형 결제(카드·계좌이체·간편결제 등 계약 수단)
- 서버 결제금액 검증, 승인·실패·중복요청 방지, 웹훅 재검증
- 결제 전 재고 예약, 실패·취소·전액환불 시 재고 자동 복원
- 결제상태와 배송상태 분리, 실제 승인된 금액만 매출 집계
- 관리자 전액환불
- CSRF 보호와 서버 전용 시크릿키 관리
- 관리자 제품 등록·수정·공개 상태 전환
- 모바일 하단 내비게이션과 반응형 UI
- 5만 원 이상 무료배송 계산

## 관리자 설정

배포 환경변수에 아래 값을 등록합니다.

```text
SECRET_KEY=충분히_긴_무작위_문자열
ADMIN_EMAIL=관리자로_사용할_이메일
TOSS_CLIENT_KEY=토스페이먼츠_클라이언트키
TOSS_SECRET_KEY=토스페이먼츠_시크릿키
SESSION_COOKIE_SECURE=1
APP_ENV=production
```

`ADMIN_EMAIL`과 동일한 이메일로 회원가입하면 관리자 권한이 부여됩니다.

## 토스페이먼츠 설정

1. 토스페이먼츠 전자결제를 신청하고 주문서형·결제창형 연동 키를 발급합니다.
2. 배포 환경변수에 서로 짝이 맞는 `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`를 등록합니다.
3. 토스페이먼츠 개발자센터에 웹훅 URL을 `https://사이트주소/payments/toss/webhook`으로 등록합니다.
4. 테스트 키로 승인·실패·전액취소를 확인한 뒤 라이브 키로 교체합니다.

시크릿키는 브라우저 코드나 GitHub에 절대 넣지 않습니다. 서버가 저장된 주문금액과 결제금액을 비교한 뒤 승인합니다.

개발 환경에서만 `APP_ENV=development`, `PAYMENT_MOCK_ENABLED=1`을 설정하면 실제 금액 승인 없이 주문 흐름을 검사할 수 있습니다. 운영 환경에서는 모의결제가 자동으로 비활성화됩니다.

## 판매 개시 전 필수 작업

1. 관리자에서 확정 제품의 가격·재고·전성분·사용법·주의사항 입력
2. 제품 상태를 `판매 중`으로 전환
3. 사업자정보·통신판매업 신고정보·고객센터·교환/반품 정책 표시
4. PostgreSQL 또는 Render 영구 디스크 등 운영용 영구 데이터 저장소 연결
5. 토스페이먼츠 테스트 결제·취소 및 웹훅 수신 확인

결제키가 없으면 결제 화면은 비활성 상태로 표시되며 주문을 결제완료로 처리하지 않습니다.

## 자동 검사

```bash
python -m unittest discover -s tests -v
```

검사 항목은 재고 예약, 모의 승인, 실패 시 재고·장바구니 복원, 결제금액 변조 차단, CSRF 차단입니다.
